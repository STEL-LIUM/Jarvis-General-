# JARVIS Chat 1.6.3

A major upgrade to the 3D design engine — models now come out as proper shaped objects, not blocks — plus a 7-day free trial and a cloud-synced design library.

## 🎁 7-day free trial
JARVIS Chat is now **free to use for 7 days** — no key needed. Just download and go. After the trial, subscribe to keep using it. (Coworkers' team codes and subscriptions work as before.)

## 🗡️ Much better 3D designs
- **Shaped parts, not blocks** — swords get real tapered blades, katanas get curved single-edged blades, axes get wedge heads, and any round object (vase, goblet, cup, lamp, chess piece) is cleanly lathed.
- **Auto-finishing on every model** — edges are softly beveled, curved surfaces smooth-shaded, and the model rests on a ground with a contact shadow. Results look manufactured, not like rough CG.
- **Parts actually connect** — a new auto-weld step pulls any stray part (eyes, legs, gear teeth) onto the body so nothing floats.
- **Materials chosen for you** — blades become steel, handles wood, cups ceramic, etc., automatically.
- **Faster + smarter generation** — JARVIS plans the parts, then writes the model; and it now uses the right-sized AI model for your GPU (no more slow CPU fallback).

## ☁️ Cloud design library
JARVIS now pulls its design library from the cloud on launch, so new shapes can be added without updating the app. Ships with a starter set built in (works fully offline).

## ✨ Also
- Fixed flickering text when dragging or resizing the panel.
- Smoother, more polished previews across the board.
- Windows installer + Linux AppImage, both pre-seeded.
